# RewardVerse — pinned runtime requirements
#
# Snapshot of the verified-working ``rewardverse`` conda env
# (captured 2026-07-09 via ``pip freeze`` inside
#  /efs/jacuzzitang/miniconda3/envs/rewardverse):
#
#   Python 3.10.20, CUDA 12.4, torch 2.6.0+cu124,
#   transformers 4.51.3, tokenizers 0.21.4, accelerate 1.13.0,
#   deepspeed 0.16.5 (ZeRO-3), flash-attn 2.7.4.post1,
#   diffusers 0.35.0, liger_kernel 0.4.1, qwen-vl-utils 0.0.14.
#
# How to use
# ----------
# Do NOT run ``pip install -r requirements.txt`` on its own — this file
# does not list torch/torchvision/torchaudio, which MUST come from the
# cu124 wheel index (not PyPI's CPU build), and it does not list
# flash-attn (needs ``--no-build-isolation`` because its setup.py imports
# torch at build time).
#
# Use the one-shot installer instead:
#
#   bash install_rm_env.sh                       # into current python
#   bash install_rm_env.sh --conda rewardverse   # fresh conda env
#   bash install_rm_env.sh --venv .venv          # fresh venv
#   bash install_rm_env.sh --no-flash            # skip flash-attn (default: install)
#   bash install_rm_env.sh --extras vllm         # also install vllm stack
#
# flash-attn is installed by default because the main training entrypoint
# ``scripts/train_8gpu_zero3_joint.sh`` passes
# ``--attn_implementation flash_attention_2`` and hard-fails without it.
#
# The installer does, in order:
#   1. pip / setuptools / wheel / packaging upgrades
#   2. torch 2.6.0 + torchvision 0.21.0 + torchaudio 2.6.0 from the cu124 index
#   3. this file (``pip install -r requirements.txt``)
#   4. flash-attn 2.7.4.post1 with --no-build-isolation (unless --no-flash)
#   5. (optional) extras: vllm/bitsandbytes for the auto-rubric image path
#   6. ``pip install -e .`` for the vision-auto-rubric package
#
# What this file pins
# -------------------
# EVERY pure-python / generic-wheel dep that ``rm_training`` and
# ``rubric_pipeline`` import at runtime, matching the verified env
# byte-for-byte on version.
#
# What this file INTENTIONALLY OMITS
# ----------------------------------
#   * torch / torchvision / torchaudio  → installed from cu124 wheel index
#     in install_rm_env.sh step 2 (must NOT come from PyPI).
#   * flash-attn                        → needs --no-build-isolation
#     (install_rm_env.sh --flash, step 4).
#   * nvidia-* cuda runtime wheels      → pulled in transitively by torch.
#   * vllm / bitsandbytes               → optional extras for the legacy
#     auto-rubric image-generation path; install via
#     ``pip install -e .[vllm]`` or ``install_rm_env.sh --extras vllm``.
